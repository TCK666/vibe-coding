## 三、接真模型（硅基流动）操作指南

系统与模型解耦：`mock_llm` 与硅基流动同说 OpenAI 兼容协议，**切换不换代码**。

1. 以 admin 登录 → 配置管理：
   - `llm.provider` → `openai`
   - `llm.base_url` → `https://api.siliconflow.cn/v1`
   - `llm.model` → 如 `deepseek-ai/DeepSeek-V3` 或 `THUDM/glm-4-9b-chat`（以账号可用模型为准）
   - `llm.api_key` → 你的 sk-xxx
   - 点"重载配置"（或保存即生效）
2. 回工作台重跑两场景。真模型会依据 system 里的表结构指南自己写 SQL，工具真实执行后由模型给结论——六部分 JSON 校验不通过时原始文本兜底落库，不会丢结果。
3. 若需切回演示模式：`llm.base_url` 改回 `http://127.0.0.1:9002` 即可。
4. 生产 MySQL：`.env` 改 `BAAS_DB_URL=mysql+aiomysql://...`，执行 `backend/sql/01_init.sql`（模型与 DDL 同构），迁移用 alembic。
