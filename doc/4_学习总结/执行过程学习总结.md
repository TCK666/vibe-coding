# 执行过程学习总结（AI 辅助开发实战复盘）

本项目从需求文档到可演示系统共 9 个里程碑、6 次提交、31 个自动化测试，全程由 ZCode/Claude Code 类 AI 代理实现。本文提炼"怎么做"和"踩了什么坑"，供后续项目复用。

## 1. 总体工作流（已被验证有效）

```
grill-me 问透(范围/技术栈/外部依赖/模型来源)
  → PRD(逐条对齐需求, 覆盖对照表自检)
  → 概要设计总纲(技术决策表 + 分层架构 + 里程碑表, 每个里程碑带验收门槛)
  → 自底向上逐里程碑开发(每步: spec → 后端 → 测试 → 前端 → 实测 → git commit)
  → 演示数据 + 接真模型(配置切换, 代码零改动)
```

关键点：
- **先把"决定性选择"摆出来让用户拍板**（范围/技术栈/认证方式/模型来源），一次问清，后面不再反复打断；
- **每个里程碑有明确的验收门槛**，测试不过不进下一步；
- **文档先于代码**：spec 写清楚接口契约/状态机/安全边界，AI 照契约实现，返工极少。

## 2. 模块五步法（用户 CLAUDE.md 约定，实测有效）

数据对象 → 原型图（HTML 静态页替代 .pen）→ spec → 后端 → 前端。
体会：**spec 是五步中最值钱的一步**——它把"要什么"翻译成 AI 可执行的精确契约（字段名/枚举/错误码/级联顺序），后续前后端并行不歪。

## 3. 踩坑实录（每条都花过真实排障时间）

### 3.1 环境与工程
- **.bat 必须 CRLF + 纯 ASCII**：AI 默认写 LF + UTF-8 中文，cmd 解析错乱 → 双击闪退。修法：`sed -i 's/$/\r/'` + 注释全英文。
- **Windows 下 `Path.write_text` 默认把 `\n` 转成 `\r\n`**：导出文件与 API 返回字节不一致。修法：`newline="\n"`。

### 3.2 FastAPI
- **multipart 的标量参数必须 `Form(...)`**：`conversation_id: int` 不加注解会被当成 query 参数 → 422。
- **Header 参数要显式 `Header(default="")`**：裸 `str = ""` 是查询参数，`Authorization` 传不进来 → 401。
- **websocket 端点只能 accept 一次**：封装层再 accept 一次直接违反 ASGI 状态机。

### 3.3 SQLite 异步（生产 MySQL 不受影响，但开发期天天撞）
- **取消不能硬来**：`task.cancel()` 让 `CancelledError` 落进 `db.commit()`，连接带着未决事务回池 → 后续写全部锁死。正解：**协作式取消**（引擎在安全点自查标志主动抛业务异常）+ 5 秒强杀兜底。
- **"读事务升级写锁"是瞬时 BUSY**：同一事务先 SELECT 后 UPDATE，SQLite 立即报锁（不等 busy_timeout）。正解：状态用纯 UPDATE 直写；消息"查序号/插消息"拆两段，唯一约束兜底重试。
- **WAL + busy_timeout 必须开**：多连接并发写是任务引擎常态。
- **aiosqlite 连接绑定事件循环**：测试端每个 WebSocket 会话是独立 loop，连接池跨 loop 复用会永久悬挂。开发库直接 `NullPool`。
- **经验法则：数据库操作的事务边界要短，await 外部服务（广播/HTTP）绝不放在事务里。**

### 3.4 前端与联调
- **vite 代理前缀别太宽**：`/auth` 整段代理把后端 302 回来的**前端路由** `/auth/callback` 也吃掉了 → 登录闭环断裂。只有端到端浏览器测试能发现这种"各自都对、拼起来错"的问题。正解：代理收窄到 `/auth/login`。
- **测试工具的怪象先查环境再改代码**：自动化浏览器里弹窗关不上/截图超时，最后发现是页面 `document.hidden=true`、rAF 冻结——动画过渡永远不结束。判断依据：DOM 状态全对 + `requestAnimationFrame` 不触发 = 工具限制，不是 bug。

### 3.5 测试策略（三层金字塔，每层抓不同的错）
1. **pytest 单测**（FakeLLM 注入，不起外部服务）：协议完整性（8 类消息全出现）、状态机、权限、边界（越界路径/超限/白名单）——快且稳。
2. **curl 实弹**：对运行中服务走真实 HTTP 链路（OAuth 四跳、上传下载字节比对）。
3. **浏览器 GUI**：真实点击流，专抓"集成缝隙"（代理、cookie、路由、渲染）。
注意：curl 行内 JSON 在 Git Bash 会坏（中文+引号），用 `--data @file`；测试收包用 daemon 线程 + 超时，防止解释器退出时挂死。

## 4. AI 协作的几个实战技巧

- **让 AI 先读证据再提问**：先翻需求文档/CLAUDE.md/桌面文件，把发现的矛盾（模板残留、缺失技能、双项目混装）连同选择题一起抛出，比空对空问"你想要什么"高效得多。
- **子代理并行**：PRD 文档、前端骨架这类规格明确的独立块交给后台子代理，主线专攻后端核心，互不阻塞。
- **给 AI 留"可切换的接缝"**：LLM 适配层从第一天就按 OpenAI 兼容形状设计（含 tool_calls 分片 index），mock→真模型只是配置；数据源同理（readonly_dsn）。
- **埋雷式演示数据**：seed 里用精确比例构造异常模式（8.0%→3.2%），并写断言自检——演示效果稳定可复现，比"随手造数据"可信。
- **每次里程碑一个 commit**，信息写清"做了什么+怎么验证的"，复盘和回滚都靠它。
