# 两场景全链路演示脚本（里程碑8）

前提：`python backend/sql/seed_demo.py` 已执行（演示数据日期相对当天动态生成，埋雷比例见下）。

## 场景一：客户行为分析

| 表 | 埋雷模式 |
|---|---|
| biz_user / biz_visit_event / biz_add_cart_event / biz_order_event | 移动端自然流量：转化率 8.0% → 3.2%、加购率 20% → 8%（其余 5 组渠道×设备平稳 ~5%/15%），对应"详情页改版导致首屏加购按钮曝光下降" |

演示提问（按顺序发 2~3 轮）：

1. `近30天下单转化率如何？为什么下降？` —— 预期：db_query 按渠道×设备聚合 → 定位移动端自然流量 3.2%（环比 8.0%），其余平稳 → 六部分结论指向详情页改版
2. `加购环节有问题吗？` —— 追加/复用证据 → 加购率 20%→8%，下降先于下单 → 收窄到详情页
3. （可选）上传《改版说明.txt》附件 → 结论引用附件佐证

## 场景二：评论反馈分析

| 表 | 埋雷模式 |
|---|---|
| biz_product / biz_rating / biz_comment / biz_refund | P-AIR-300 空气炸锅（批次 B2026-09）：评分 4.4 → 2.8，近30天 40 条评论中 30 条"异味/涂层脱落"，质量问题退款占比 12% → 38% |

演示提问：

1. `近30天商品评分怎么样？有没有明显下滑的商品？` —— db_query 按商品聚合评分 → P-AIR-300 均分 2.8 垫底
2. `差评都集中在什么问题上？` —— text_search/db_query 评论 → 异味、涂层脱落
3. `退款数据能不能印证？` —— biz_refund → 质量问题退款 12% → 38% → 结论：批次质量缺陷并已传导至退款

- 追问时模型自动携带历史与摘要（>阈值触发压缩）
