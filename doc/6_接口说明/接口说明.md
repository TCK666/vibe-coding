# 接口说明

- 基地址：`http://localhost:8000`（前端经 vite 代理 `/api`、`/auth/login`）
- 鉴权：除 `/auth/*`、`/healthz` 外均需 `Authorization: Bearer <JWT>`（登录后获得）
- 统一响应包：`{"code": 0, "message": "ok", "data": ...}`；失败时 `code` 为错误码字符串（如 `TASK_RUNNING`），HTTP 状态码同步表达（400/401/403/404/409/500）
- 机器可读全量契约：同目录 `openapi.json`，交互式文档 `http://localhost:8000/docs`
- 长连接不在 OpenAPI 内：`WS /api/chat/ws/chat?websocket_token=&conversation_id=`（协议见 §3）

## 1. 认证（对接认证中心，OAuth2 授权码）

| 接口 | 说明 |
|---|---|
| GET /auth/login | 302 → 认证中心授权页（state 防CSRF，5分钟有效） |
| GET /auth/callback?code&state | 换令牌 → 拉用户信息 → users upsert → 签发本系统 JWT → 302 回前端 `/auth/callback?access_token=..&expires_in=..` |
| GET /api/auth/me | 当前用户 `{user_id, external_user_id, username, display_name, role}` |

## 2. 会话 / 消息 / 附件

| 接口 | 请求 | 响应(data) |
|---|---|---|
| POST /api/chat/create | `{title?}` | `{conversation_id, title, status}` |
| POST /api/chat/update | `{conversation_id, title}` | 同上 |
| POST /api/chat/delete | `{conversation_ids: []}` | `{deleted: []}`（级联删记录+文件目录） |
| GET /api/chat/ls | - | `{conversations: [{conversation_id,title,status,last_message_at}]}` |
| GET /api/chat/ls/{cid} | - | `{conversation, messages:[{message_id,role,message_type,content,seq_no,attachments,created_at}], conversation_attachments}` |
| POST /api/attachment/upload | multipart `conversation_id` + `file` | `{attachment_id, file_name, file_path, parse_status}` |
| POST /api/attachment/delete | `{attachment_id}` | `{attachment_id}` |
| GET /api/attachment/get?attachment_id= | - | 文件流 |
| GET /api/attachment/ls?conversation_id= | - | `{attachments: [...]}` |

## 3. 长连接与分析任务

| 接口 | 说明 |
|---|---|
| POST /api/chat/ws-token | body `{conversation_id}` → `{websocket_token, expires_in}`（一次性，默认30s） |
| WS /api/chat/ws/chat | 参数 `websocket_token`、`conversation_id`；客户端发 `{type:"chat",content}` / `{type:"cancel",task_id}` / `{type:"ping"}`；非法令牌 close(4401) |
| GET /api/tasks/{task_id} | `{task_id, task_status, current_step, started_at, finished_at, error_message}` |

WS 下行 8 类消息（信封 `{type, data, ts}`，字段对齐需求 2.1.10）：
`message_start(task_id,conversation_id)` → `task_status(task_status,current_step)` → `message_delta(delta_text)`×N → `tool_start(tool_name)` / `tool_finish(tool_name,tool_result_summary)` → `task_status` → `result_ready(result_id)` → `task_status(success)` → `done(finished_at)`。失败路径：`error(task_id,error_message)` + `done`。

## 4. 结果

| 接口 | 说明 |
|---|---|
| GET /api/results/{task_id} | `{problem_definition, key_metrics[], evidence_list[], conclusion_text, missing_data_text, next_action_text, result_markdown, result_file_path, created_at}` |
| GET /api/results/{task_id}/download | 导出文件流 `analysis_{task_id}.md` |
| GET /api/results/latest/{conversation_id} | 会话最新结果（前端切会话回放用） |

## 5. 管理端（role=admin，否则 403）

| 接口 | 说明 |
|---|---|
| GET /api/admin/configs | `{configs:[{config_key,config_value,config_group,updated_at}]}` |
| POST /api/admin/configs | `{config_key, config_value}` upsert，即时生效 |
| POST /api/admin/reload | 重建配置缓存 → `{status:"ok", message:"已重载 N 项配置并即时生效"}` |
| GET /api/admin/logs?task_id=&limit= | `{logs:[{log_id,task_id,log_level,log_type,log_content,created_at}]}` 倒序 |

## 6. 主要错误码

`AUTH_*`（未登录/过期/无权限）、`CONV_NOT_FOUND`、`ATTACHMENT_NOT_FOUND`、`FILE_TOO_LARGE`、`FILE_PATH_INVALID`、`TASK_RUNNING`（409 单会话单任务）、`TASK_NOT_RUNNING`、`TOOL_SQL_INVALID`、`TOOL_CMD_FORBIDDEN`、`NOT_IMPLEMENTED`
